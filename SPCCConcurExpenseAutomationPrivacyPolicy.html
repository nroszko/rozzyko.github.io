Privacy Policy

SPCC Concur Expense Automation — Last updated: September 12, 2026

SPCC Concur Expense Automation ("the extension") is an internal browser extension built for Pembina Pipeline Corporation employees. It is not distributed publicly and is only intended for use by authorized internal users on company-managed systems. This policy explains what data the extension accesses, why, and what happens to it.

What the extension does

The extension automates a single internal workflow: importing the list of employees scheduled to work a given shift from the company's SchedulePro system into an SAP Concur expense report or an internal Microsoft Forms expense-tracking form, so users don't have to type in attendees by hand.

What data it accesses

  • SAP Concur session identifier. When you're logged in to the company's SAP Concur instance, the extension reads a session identifier already present on the page (window.cnqr.coreui.headerProps). This is used only to verify, via an internal Power Automate flow, that you are an authorized user and to obtain short-lived SchedulePro API credentials on your behalf.
  • SchedulePro roster data. The extension calls the company's SchedulePro API to retrieve employee names, employee numbers, and scheduled shifts for a date/shift you select, in order to match and pre-fill attendees.
  • Form field values you've already entered. The extension reads values you have entered on the Concur or Forms page (such as the date and shift type) to know what roster to fetch, and writes attendee selections / email addresses back into that page.

Where data goes

  • Your Concur session identifier is sent, over HTTPS, to an internal Power Automate flow operated by Pembina, solely to confirm you are on the authorized user list and to issue scoped, time-limited SchedulePro credentials. It is not sent anywhere else and is not used for any other purpose.
  • Roster requests are sent, over HTTPS, directly to the company's SchedulePro API (api.scheduleproweb.com) using those credentials.
  • No data is sent to the extension developer, to any analytics or advertising service, or to any third party outside of Pembina's own SAP Concur, SchedulePro, and Power Automate systems.

What's stored, and for how long

The extension uses the browser's local extension storage (chrome.storage.local), which stays on your own device and is not synced or transmitted elsewhere. It stores:

  • Your Concur session identifier and a cache of temporary SchedulePro credentials, for up to 1 hour, so you don't have to re-authenticate on every request.
  • A cache of the SchedulePro employee list, for up to 12 hours, to speed up repeated lookups.

All of this data is cleared automatically whenever the browser restarts or the extension is installed/updated, and can be cleared manually at any time from the extension's popup.

What the extension does not do

  • It does not track browsing activity outside the specific SAP Concur, Microsoft Forms, and SchedulePro pages it operates on.
  • It does not use cookies, analytics, or advertising identifiers.
  • It does not sell or share data with third parties.
  • It does not run any code that isn't packaged in the extension itself (no remotely loaded scripts).

Who this applies to

This extension is built for, and restricted to, authorized Pembina Pipeline Corporation employees with access to the company's internal SAP Concur, SchedulePro, and Microsoft Forms systems. It is not intended for use by the general public.

Changes to this policy

If how the extension handles data changes, this page will be updated and the "Last updated" date above will reflect the change.

Contact
